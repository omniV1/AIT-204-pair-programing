Section 1 — Recurrent Neural Networks (RNN) Fundamentals
Concept
What Makes an RNN "Recurrent"?

Unlike feed-forward networks that process each input independently, a Recurrent Neural Network (RNN) maintains a hidden state that carries information from one time step to the next. This gives the network a form of memory.

At each time step $t$, the RNN computes:

$$ h_t = \tanh(W_{xh} \cdot x_t + W_{hh} \cdot h_{t-1} + b_h) $$

where:

  • $x_t$ is the input at time step $t$
  • $h_{t-1}$ is the hidden state from the previous step
  • $W_{xh}$ and $W_{hh}$ are learnable weight matrices
  • $b_h$ is a bias term

Problem
The Vanishing Gradient Problem

When RNNs are trained on long sequences, gradients shrink exponentially as they are backpropagated through time. If the gradient at step $T$ is:

$$ \frac{\partial L}{\partial h_1} = \frac{\partial L}{\partial h_T} \cdot \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}} $$

Each factor $\frac{\partial h_t}{\partial h_{t-1}}$ is typically less than 1. After multiplying many such factors, the gradient approaches zero, making it impossible for the network to learn long-range dependencies.

Why this matters for weather: Temperature patterns often depend on conditions from days or weeks earlier. A standard RNN cannot "remember" that far back. This is exactly why LSTMs were invented.

Section 2 — LSTM Architecture & Gates
Concept
The LSTM Cell

An LSTM (Long Short-Term Memory) cell adds a cell state $C_t$ that acts like a conveyor belt — information flows through it with minimal modification. Three gates control what information enters, stays, or leaves the cell state.

Forget Gate — What to Discard

The forget gate decides which information from the previous cell state to throw away. It outputs a value between 0 (completely forget) and 1 (completely keep) for each dimension.

$$ f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) $$

Temperature example: If the model learned that yesterday's pressure reading is no longer relevant for today's temperature prediction, the forget gate will output values near 0 for those dimensions, effectively erasing that information.

Input Gate — What to Store

The input gate has two parts: a sigmoid layer that decides which values to update, and a tanh layer that creates a vector of candidate new values.

$$ i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) $$ $$ \tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) $$

The cell state is then updated:

$$ C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t $$

Temperature example: When a cold front arrives, the input gate recognizes this as important new information and writes it into the cell state for future predictions.

Output Gate — What to Output

The output gate controls which parts of the cell state become the hidden state (the actual output of this time step).

$$ o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) $$ $$ h_t = o_t \odot \tanh(C_t) $$

Temperature example: The cell state may contain long-term seasonal trend data, but the output gate only passes the information relevant for the next hour's prediction.

Section 4 — Min-Max Normalization
Concept
Why Normalize?

Neural networks learn best when input features are on a similar scale. Temperature ranges from roughly −20°C to +40°C, while atmospheric pressure ranges from 900 to 1100 mbar. Without normalization, the model would be dominated by the larger-scale features.

Min-Max Normalization scales each feature to the range $[0, 1]$:

$$ x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} $$

Section 5 — Sliding Window & Sequence Creation
Concept
Creating Input-Target Pairs

Time-series forecasting requires converting a flat sequence of values into input-target pairs. We use a sliding window approach: given a window of $L$ consecutive observations, the model uses them to predict the next value.

$$ \text{Input: } [x_t, x_{t+1}, \ldots, x_{t+L-1}] \quad \rightarrow \quad \text{Target: } x_{t+L} $$

Section 6 — Model Architecture & Training
Architecture
Our LSTM Model

The temperature forecasting model uses a stacked LSTM architecture:

Layer 1: LSTM — input_size=1, hidden_size=64, num_layers=2, dropout=0.2
Layer 2: Linear (Fully Connected) — 64 → 1 (single temperature output)

Loss Function: MSE (Mean Squared Error)
Optimizer: Adam (lr = 0.001)
Scheduler: ReduceLROnPlateau (patience=5, factor=0.5)

Why stacked LSTMs? The first LSTM layer learns lower-level temporal patterns (hourly fluctuations), while the second layer captures higher-level patterns (multi-day trends). This hierarchical representation is similar to how deeper CNN layers capture more abstract spatial features.

Concept
Loss Function — Mean Squared Error

For regression tasks (predicting a continuous value like temperature), we use MSE:

$$ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$

where $y_i$ is the actual temperature and $\hat{y}_i$ is the model's prediction. Squaring the errors penalizes large mistakes more heavily than small ones.

Section 7 — Evaluation & RMSE
Concept
Root Mean Squared Error (RMSE)

While MSE is used for training, we evaluate with RMSE because it returns an error value in the same units as the target (degrees Celsius), making it interpretable.

$$ \text{RMSE} = \sqrt{\text{MSE}} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2} $$

An RMSE of 2.5 means the model's predictions are, on average, about 2.5°C away from the true temperature.

Concept
Chronological Train/Test Split

Unlike classification tasks where data can be shuffled, time-series data must maintain temporal order. We use a chronological split:

Training Set: First 90% of the data (2009 – mid 2015)
Test Set: Last 10% of the data (mid 2015 – 2016)
Why no shuffle? Shuffling would leak future information into the training set. The model must only learn from past data to predict the future — just like in a real deployment scenario.
